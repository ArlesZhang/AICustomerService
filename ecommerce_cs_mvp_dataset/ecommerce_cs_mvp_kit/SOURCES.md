# 公开真实语料来源（供后续补充）

> 使用原则：先核实原始仓库、下载方式、许可证、隐私和再分发条款。公开可访问不等于可以任意商用或打包再分发。本 MVP 包不包含这些语料的原始数据。

1. **JDDC Corpus（京东电商多轮对话）**
   - 论文：https://aclanthology.org/2020.lrec-1.58/
   - 项目入口：https://github.com/SimonJYang/JDDC-Baseline-Seq2Seq
   - 用途：真实中文电商多轮对话、上下文依赖、任务型对话研究。
   - 注意：不同版本规模和获取方式可能不同；先核实数据下载、许可证和数据字段。

2. **SIGdial 中文对话语料目录（包含淘宝服装、美妆客服数据集等）**
   - 目录：https://sigdial.github.io/sigdial-resources/corpora.html
   - 用途：服务满意度、情绪、客服语言风格等研究。
   - 注意：请从目录定位原始论文/作者数据入口，核实访问和使用条件。

3. **ECCSQA / 电商客户与客服聊天数据集聚合页**
   - 介绍页：https://www.jizhi-dataset.top/zh/dataset/19
   - 用途：多品类客服表达补充。
   - 注意：这是聚合页；应进一步确认原始数据发布者、来源、许可、样本真实性与字段质量。

4. **Chinese-Ambiguous-Reference**
   - 仓库：https://github.com/ygan/Chinese-Ambiguous-Reference
   - 用途：指代消解、澄清问题、真实购物交互中的模糊表达。
   - 注意：覆盖线上与线下购物场景，不应当作完整的电商售后政策数据集。

## 如何把真实语料加入本项目
保留原始数据的 source_id、原始样本 ID、许可、采集方式、是否脱敏、用途限制。只抽取适合测试的用户表达，必要时ai生成/人工改写为测试输入；不要把原始客服回复直接当作星桥优选的标准答案，因为商家政策与业务数据并不相同。
