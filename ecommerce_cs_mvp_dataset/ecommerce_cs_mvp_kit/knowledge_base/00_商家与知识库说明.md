# 星桥优选 MVP 知识库说明

> 重要：星桥优选是虚构商家，本文档是为智能客服项目构造的可复现实验数据，不代表任何真实平台的政策。
> 统一规则版本：2026-10-01。测试集、知识库和 mock API 必须使用同一版本。

## 知识分类
- 商品知识：商品属性、规格、适用场景、库存演示数据。
- 交易规则：取消订单、支付、优惠券、发票。
- 售后政策：退货、换货、质量问题、运费、退款时效。
- 服务流程：身份核验、澄清问题、转人工和安全边界。

## 设计原则
1. 不能把实时订单状态、库存、物流节点写死在 RAG 知识里；应调用 mock API。
2. 未明确提供的属性不得推测。
3. 质量问题需审核，不提前承诺退款。
4. 规则不完整、冲突或涉及人工审批时转人工。
5. 所有测试记录通过 case_id 与评估集对应。
