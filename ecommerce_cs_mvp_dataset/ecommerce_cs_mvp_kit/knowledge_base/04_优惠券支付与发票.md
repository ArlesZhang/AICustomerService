# 优惠券、支付与发票
- policy_id: POL-PAY-001
- version: 2026-10-01
- status: active

## 优惠券
优惠券适用范围、门槛、有效期和叠加规则以具体活动规则为准。不得默认两张优惠券或优惠券与其他促销可叠加。若缺少活动 ID 或规则文本，应向用户询问或转人工。

## 支付问题
支付是否成功、是否重复扣款以支付/订单 API 为准。不得要求用户提供银行卡密码、短信验证码或完整支付凭证。重复扣款争议转人工核查。

## 发票
订单完成后可申请电子发票。抬头和税号由用户确认。已开票订单的红冲、重开或抬头变更需转人工，不能承诺即时完成。
