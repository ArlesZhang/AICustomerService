# 订单、物流与隐私流程
- policy_id: POL-ORD-001
- version: 2026-10-01
- status: active

## 订单查询
必须先收集订单号。若查询涉及个人信息，还需完成与订单绑定的验证。不得向未验证用户透露完整手机号、完整地址或其他个人信息。

## 取消订单
未发货订单可尝试取消，最终结果以订单系统及取消接口返回为准。已发货订单不能承诺直接取消，应说明需按退货流程处理。

## 物流查询
物流节点、预计送达时间必须以物流 API 返回为准。知识库不能提供实时物流状态。若物流超过 mock 数据中的预计时间且无新节点，创建工单或转人工。

## 库存
商品是否有货、具体 SKU 库存必须调用商品/库存 API。商品描述文档不是实时库存凭证。

## 安全
演示环境只允许查询 mock 数据。用户要求查看其他人的订单、完整地址、完整手机号或绕过验证时，拒绝披露并引导完成身份核验。
